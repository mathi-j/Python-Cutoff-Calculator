# Python Cutoff Calculator

## About
This is my first Python project. It calculates cutoff marks using Maths, Physics, and Chemistry marks.

## Features
- Accepts marks from the user.
- Validates marks between 0 and 100.
- Calculates cutoff marks if all subjects are passed.
- Displays passed and failed subjects.
- Handles invalid text input.

## Cutoff Formula
Cutoff = Maths + (Physics / 2) + (Chemistry / 2)
